## 1. 这个平台是做什么的

一句话：**用真实的历史行情和每天的最新行情，模拟交易各种风格的股票策略，看哪种在扣除各种成本后真正靠谱，再决定要不要照着它去真实交易。**

它能帮你做这些事：

| 你想知道的 | 平台怎么回答 |
|---|---|
| 某种选股思路（比如「买便宜的好公司」）过去几年表现如何？ | 用 2018 年以来的真实行情**回测**，给出收益、风险、每一笔交易 |
| AI 能不能把策略改得更好？ | 让 AI 研究员提出改进方案，由程序严格检验，通过了才采用 |
| 历史好看，现在还管用吗？ | 每天收盘后按策略做**模拟交易**（实时跟踪），用真实的新行情检验 |
| 每天该买卖什么？ | 每个交易日收盘后生成第二天的调仓清单，推送到微信 |
| 我真去交易了，和模拟差多少？ | 导入券商的成交记录，自动对比实盘和模拟 |
| 这个策略能不能上实盘了？ | 五项「可实盘检查」全部通过才会标记「可实盘」 |

平台目前只做 **A股**（沪深两市的股票和场内基金），只做多（只买入、不做空），不加杠杆。

## 2. 先弄懂六个基本概念

读懂这六个词，就能看懂平台的大部分页面。

### 2.1 策略

一套**事先写死的买卖规则**，比如：

> 「每 20 个交易日，从沪深300 的成分股里，挑市盈率最低、且净资产收益率较高的 30 只股票，每只买一样多的钱；某只股票从买入价跌了 15% 就卖掉。」

规则写死的好处是**可以拿历史数据检验**，而且执行时不受情绪影响。平台里每条策略都有一种**风格**（价值投资、趋势跟随、防御稳健……），方便你按自己的偏好挑选。

### 2.2 回测

**把策略放到过去的行情里「假装」执行一遍**，看看如果当年这么做会怎样。

平台的回测尽量贴近真实交易：今天收盘后才决定，第二天开盘才成交；买卖要交佣金、印花税；涨停买不进、跌停卖不出、停牌不能交易；只能按 100 股的整数倍买。

> 回测好 ≠ 将来好。规则如果是「照着历史答案调出来的」，回测会非常漂亮，但换一段行情就失灵，这叫**过拟合**（见第 9 章）。平台的很多设计都是为了防止被过拟合骗。

### 2.3 版本与冠军

策略的规则会被修改（被 AI 或被你），每改一次就产生一个新**版本**（v1、v2、v3……）。每条策略同一时间只有一个**冠军版本**——当前正式使用的那一版。新版本要通过严格检验（第 6.3 节）才能取代冠军。

### 2.4 三段时间：开发期、留出期、实时跟踪

为了防止「拿考题当练习题」，历史被切成几段，各有用途：

| 时间段 | 默认范围 | 用途 | 打个比方 |
|---|---|---|---|
| **开发期** | 2018～2024 年 | AI 和你可以反复看、反复改规则，升级检验也在这里做 | 平时的练习题 |
| └ 其中训练 | 2018～2022 年 | 开发期的前半段 | |
| └ 其中验证 | 2023～2024 年 | 开发期的后半段 | |
| **留出期** | 2025 年至今 | **永远不参与修改规则**，只用来看结果 | 期末考试，考前不许看 |
| **实时跟踪** | 开始跟踪那天起 | 每天用全新的行情模拟交易 | 真正上岗工作 |

判断一个策略靠不靠谱，**留出期和实时跟踪比开发期重要得多**。开发期表现再好，留出期一塌糊涂，多半是过拟合。

### 2.5 实时跟踪（模拟账户）

你选中一个策略或组合后，可以「开始实时跟踪」：平台给它开一个**模拟账户**（默认 100 万虚拟本金），从下一个交易日起，每天收盘后按规则决定第二天买卖什么，第二天开盘按真实价格成交。它和回测的区别是：**用的是你选中之后才发生的行情，没有任何「事后诸葛亮」的可能**，所以是最诚实的检验。

同时会开一个「买入并一直持有沪深300ETF」的对照账户，方便比较「这个策略到底比简单买指数强多少」。

### 2.6 多风格组合

把钱分给几条不同风格的策略同时运行，比如价值、ETF 轮动、防御各三分之一。不同风格在不同行情里各有输赢，放在一起通常比单押一条**更平稳**。平台目前实测下来证据最充分的做法就是**等权的多风格组合**（第 10 章）。

## 3. 第一次使用

### 3.1 打开网址、登录或注册

在电脑或手机浏览器打开部署好的地址，例如 **http://服务器地址:18080**（部署方法见 [DEPLOY.md](DEPLOY.md)）。

- **管理员第一次打开**：页面会让你填写**首次设置码**，并设置管理员（用户名 `admin`）的登录密码（至少 8 位）。设置码在服务启动日志里（搜「设置码」），也保存在数据目录下的 `setup-code.txt`；只有能登录服务器的人看得到，别人无法抢先设置。用过后自动删除。
- **其他人**：管理员在「用户管理」里打开「开放注册」后（新安装默认关闭），登录页会出现「注册」，自己设用户名和密码（同一台设备每小时最多注册 5 个账户）。注册后直接进入。
- **之后**：用用户名和密码登录，每台设备登录一次，30 天内不用再输。
- 右上角显示当前用户名，点开可以：修改密码、退出所有设备、退出登录；管理员还有「用户管理」（开放 / 关闭注册、停用 / 启用账户、为忘记密码的用户重设密码）。
- 同一台设备 15 分钟内连续输错 5 次，会被锁 15 分钟。
- **普通用户忘记密码**：请管理员在「用户管理」里重设。
- **管理员忘记密码**：需要能登录服务器的人执行下面的命令清除管理员密码，再打开页面重新设置：

  ```bash
  cd ~/stockarena/backend && uv run python -m app.auth reset-password
  ```

  命令会打印新的首次设置码，重新设置密码时填写。Docker 部署的命令见 [DEPLOY.md](DEPLOY.md) 第 8 节。

第一次进入会弹出「使用说明」，说明这是模拟工具、不构成投资建议，点「我已了解」后不再出现。

#### 3.1.1 多个用户怎么分

| | 管理员（admin） | 普通用户 |
|---|---|---|
| 7 条 AI 风格策略 | 自己的，设为**公共**：可以修改、优化、跟踪 | 可以查看（规则、回测、版本、研究记录、今日信号）、**另存为自己的策略**；不能修改、优化、跟踪 |
| 自己建的策略、另存的策略、组合、实时跟踪、实盘对照、自选股、首页明星股、消息推送、AI 对比 | 只有自己看得到 | 只有自己看得到 |
| 模型供应商（AI 模型） | 自己配置 | 自己配置，不能用别人配置的模型；没有模型就不能用 AI 优化、AI 复核、自选股监控 |
| 交易成本 | 自己设置；公共策略显示的回测结果按管理员的设置 | 自己设置，只影响自己的策略（另存公共策略时按自己的设置重新回测） |
| 数据准备与数据质量、系统状态、技能、用户管理 | ✅ | — |

- 组合只能用自己的策略；想用公共策略，先「另存为新策略」。另存后的副本不会因为管理员的 AI 优化而变化。
- 技能（如腾讯自选股 westock）用的是管理员个人的授权，只在管理员的 AI 复核和自选股监控里使用。

### 3.2 认识界面

左侧菜单从上到下：

| 菜单 | 用来做什么 | 常用程度 |
|---|---|---|

| **策略库** | 所有策略的列表 | ★★★ |

| **每日信号** | 所有跟踪中的策略 / 组合今天要买卖什么 | ★★★ |

| **使用手册** | 就是本手册：左侧目录跳转，顶部输入关键字搜索（多个词用空格分开），回车跳到下一处 | 随时查 |

右上角：后端状态（绿色「后端正常」）、问号按钮（打开本手册）、深色 / 浅色切换、账号菜单。

### 3.3 初次设置清单

**管理员**（全新安装时，按顺序做一遍）：

1. **设置管理员密码**（3.1，需要首次设置码）。
2. **准备数据**：在「策略库」点「准备数据」，下载股票池的历史成分、行情、财报和行业分类，第一次约 20～30 分钟，之后每个交易日晚上自动增量更新。
3. **创建风格策略库**：数据准备好后点「创建 N 种风格策略」，一键生成 7 种初始策略（公共策略，所有用户都能查看和另存）。
4. **需要多人使用时**打开注册：右上角账号菜单 →「用户管理」→「开放注册」。

**每个用户**（大约 10 分钟）：

1. **填交易成本**：「配置中心 → 交易成本」，按你券商的实际佣金填写（第 5.8.4 节）。不填就按默认的万 2.5、最低 5 元计算。
2. **添加 AI 模型（可选）**：「配置中心 → 模型供应商」（第 5.8.1 节）。不加也能用回测、组合、模拟和信号，只是没有 AI 优化和复核。
3. **配置消息推送（可选）**：「配置中心 → 消息推送」，添加一个推送通道，点「发送测试」确认手机能收到（第 5.8.5 节）。
4. **建一个多风格组合**：在「多风格组合」里选几条风格不同的策略（自己的，或从公共策略另存的），看回测报告满意后点「开始实时跟踪」（第 5.3 节）。

## 4. 推荐的使用流程

### 4.1 整体路线

```
挑选策略 / 组合 ──► 实时跟踪（模拟） ──► 跟踪满 3 个月，「可实盘」检查通过 ──► 小资金实盘 ──► 实盘对照，持续核对
        ▲                    │
        └── 健康度变差、对账偏差大时，回头复查 ◄──┘
```

关键原则：**不要因为回测好看就直接上实盘**。至少让它在实时跟踪里跑满 3 个月（约 60 个交易日），看它在全新行情里的表现。

### 4.2 每个交易日（约 5 分钟）

收盘后（16:20 以后）：

1. **看微信推送**：如果当天有调仓，会收到「【调仓提醒】组合名：MM-DD 开盘 卖 X 买 Y」，里面有每笔订单的股票、股数、参考金额。
2. 打算实盘的话，第二天开盘按清单下单（第 7 章）。
3. 没有推送说明当天不用调仓，或者你还没配置推送——也可以直接打开「每日信号」页看。

### 4.3 每周（约 15 分钟）

1. 「多风格组合」→ 选中组合 →「信号与实时跟踪」：看跟踪以来的收益和对照（沪深300），看**对账与健康度**是不是「一致」「正常」。
2. 如果在实盘：「实盘对照」→ 导入这周的券商成交 → 看对比报告。

### 4.4 每月或有空时

- 「可实盘检查」的结论有变化时会推送微信，不必天天看。
- 「系统状态 → 数据质量」看有没有标红的数据错误（有新错误也会推送）。
- 想试新思路：在策略详情手动改规则，或让 AI 优化几轮（第 5.2.3 节），但请先读第 10 章对 AI 优化效果的说明。

## 5. 各页面怎么用

### 5.0 首页

打开平台先看到的页面，交易时段每 30 秒自动刷新：

- **市场概览**：A 股（上证、深证成指、创业板、沪深300、科创50）、港股（恒生、恒生科技、国企指数）、美股（道琼斯、标普500、纳斯达克）的最新点位、涨跌幅和最近约 3 个月的走势小图；A 股另有上涨 / 下跌家数、涨停 / 跌停家数和两市成交额。点指数进入它的详情页。
- **我的组合：今天 vs 基准**：每个实时跟踪的组合（纯规则账户、AI 复核账户）和单独跟踪的策略，最近一个交易日的收益、基准收益和超额，以及跟踪以来的累计表现。交易时段另有「盘中估算」：按当前持仓和实时价估算的当天收益，只供参考，正式结果以收盘后的净值为准。
- **明星股**：你关注的一组股票的实时价格，点「编辑」可以搜索添加、调整顺序、删除（最多 30 只）。默认是 A 股、港股、美股的一些大市值公司。

> 首页上的涨跌只是行情背景。系统化策略不应因为某一天大涨大跌就临时干预，判断策略好坏请看跟踪以来的超额和可实盘检查。

### 5.0.1 自选股

左侧菜单「自选股」，或在股票详情页点「加入自选」（最多 30 只）。

- **AI 盯什么**：每天晚上 21:15（周末也查，公告和新闻不只在交易日发布），AI 阅读每只自选股新增的公告（A 股）、新闻和当天走势，找出你需要知道的事：业绩大幅变化、立案调查、监管问询、大股东增减持、质押风险、重组并购、回购分红、重大合同、停复牌、ST 风险、异常波动的原因等。例行公告不提醒。
- **它写什么**：每件事一条记录：级别（一般关注 / 重要 / 重大）、利好 / 利空 / 中性、发生了什么（引用原文里的数字）、意味着什么、影响多大，并附原文链接。**AI 不预测涨跌、不给买卖建议**，买卖由你决定。
- **推送**：默认「重要」及以上推送微信（「自选股提醒」），可改为全部推送或只推「重大」。
- **省资源**：没有新公告新闻、当天涨跌也不到 5% 的股票不调用 AI；看过的公告新闻不会重复提醒。AI 调用失败时，资料留到下次重试。
- **也能看到平台视角**：表格里会显示哪些成员策略最近选中了它、跟踪账户是否持有；点股票名进入详情页看因子排名。
- **权重**：0～3，默认 1。只给「自选倾斜」账户用（见 5.3.2），不影响其他任何账户。
- 在页面底部选择监控用的模型（自己配置的任一模型）。

### 5.1 策略库

每条策略一张卡片，按开发期夏普从高到低排：

| 卡片上的内容 | 意思 |
|---|---|
| 名称和 `vN` | 策略名、当前冠军是第几版 |
| 小曲线 | 蓝线是冠军版本的收益，灰线是沪深300；浅色底的部分是验证期和留出期 |
| 开发期夏普 | 2018～2024 年的风险调整后收益（越高越好，第 6.1 节） |
| 折算可信度 | 考虑到这条策略已经被改了多少次，冠军「真本事」大于 0 的概率。改的次数越多、优势越小，可信度越低 |
| 留出期收益 | 2025 年以来的累计收益——**最该看的数字之一** |
| 最大回撤 | 开发期里最惨的一次下跌幅度 |
| 可实盘标签 | 待观察 / 未通过 / 可实盘（第 6.4 节） |
| 自动 | 打开后每个交易日晚上自动让 AI 优化（会消耗 AI 调用费用或本地显卡时间） |
| 优化 | 立即让 AI 优化一次 |

点卡片进入**策略详情**。

**新建策略**（右上角）：自己设计一条策略。

1. **一句话描述（可选，需要 AI 模型）**：用中文写下想法，例如「低估值、高股息、过去一年回撤小的大盘股，每月调仓，同一行业不超过 3 只」，选一个模型，点「AI 生成规则」。AI 只负责把描述翻译成规则，不看任何回测结果；平台的规则表达不了的条件（如分析师评级、新闻情绪、日内交易）会在「AI 说明」里逐条列出，**不会被悄悄丢掉**。勾选「在当前规则上修改」可以接着用一句话调整。生成后请检查下面的规则再试算。
2. 填名称和风格说明（说明这条策略想抓住什么，AI 优化时会参考）。
3. 选起点：空白（一个动量因子），或某个风格模板（如价值投资的初始规则）。想在已有策略上改，用策略详情里的「另存为新策略」（第 5.2 节）。
4. 选股票池：沪深300 或中证800（都是全时点）。完整数据还没准备好时，可以先用「快速体验」股票池（见下面的说明）。
5. 用表单编辑规则：选股范围（股票 / ETF、上市天数、成交额、行业）、打分因子（最多 6 个，可设方向、权重、行业内排名）、过滤条件、持有数量和权重、调仓间隔、大盘择时、止损。也可以切换到 JSON 直接改。
6. 点「试算」：只回测开发期（2018～2024），不保存，可以反复调整。**试算不显示留出期**——如果每改一次都看 2025 年以来的表现，改到它好看为止，留出期就失去了「从没见过的新行情」的意义。**每次试算都计入这条策略的测试次数**：反复改到开发期好看本身就是在开发期上做选择，所以之后 AI 优化的升级门槛会相应收紧，DSR 也把这些试算算作尝试。对话框底部会显示已试算几次。
7. 选择是否让 AI 优化：设置研究模型后，可以随时手动「优化」，也可以开启每晚自动优化（默认关闭，原因见第 10 章）。不设研究模型也可以，策略照样能回测、跟踪。
8. 点「创建」：按完整流程回测（含留出期和稳健性检验），成为这条策略的第 1 版（冠军）。之后和其他策略一样，可以手动改规则、让 AI 优化、开始实时跟踪。

**快速体验**（新安装时）：完整数据（沪深300 全时点，几百只股票）第一次要准备 20～30 分钟。管理员可以先点「快速开始」：只下载上证50 + 10 只核心 ETF（约 60 个标的，年份和完整数据一样从 2016 年起），几分钟就能用「新建策略」选「快速体验」股票池试算第一个策略，完整数据随后自动在后台准备。注意快速体验只用**今天**的上证50 成分回看历史，有幸存者偏差（后来没进上证50 的股票被提前排除了），回测明显偏乐观，所以它上面的策略**不能通过「可实盘检查」**；完整数据好了以后，请在全时点股票池上重新创建。

### 5.2 策略详情

顶部是风格说明、研究模型（哪个 AI 负责优化）、版本数；右上角有「优化 N 轮」按钮和设置菜单（研究设置、手动编辑规则、另存为新策略、因子库、归档；管理员还可以「设为公共 / 取消公共」）。

打开的是别人的公共策略时（标「公共」），页面只读：可以看冠军版本、交易明细、资金容量、版本历史和研究记录，右上角只有「另存为新策略」和「因子库」。

下面有若干标签页：

#### 5.2.1 冠军版本

- **中文规则**：把策略规则翻译成大白话，比如「每 20 个交易日调仓；在沪深300 成分股中排除 ST……按盈利收益率（越高越好，权重 50%）和 ROE（越高越好，权重 50%）综合打分，持有前 30 名，等权……」。
- **改动理由与检验结论**：这一版相对上一版改了什么、为什么改、凭什么通过了检验。
- **收益曲线**和**指标表**：开发期、其中训练、其中验证、留出期分别的收益、夏普、回撤等。
- **分年收益**：每年赚了多少、指数赚了多少、跑赢多少（超额）。看它是不是每年都还行，还是靠某一年大赚撑起来的。
- **稳健性**：把规则里的数字随机改动 ±20%，看表现掉多少（第 6.1 节）。
- **开发期诊断**：胜率、盈亏比、卖出原因统计等。

#### 5.2.2 交易明细

回答「到底买了什么、赚亏多少、为什么这么买卖」。先选区间（开发期 / 训练 / 验证 / 留出 / 全部），再看子标签：

| 子标签 | 能看到什么 |
|---|---|
| 概览 | 成交笔数、胜率、平均赚多少 / 亏多少、平均拿多少天、费用；**卖出原因统计**（掉出排名、止损……各自的次数和盈亏）；赚亏最多的 10 只 |
| 调仓记录 | 每次调仓选了谁、卖了谁。展开能看到每只入选股票的**综合排名**（如「3/61」= 61 只可选里排第 3）和**每个因子的位置**（「前 5%」= 在这个指标上排在前 5%）；每只卖出股票的**具体原因** |
| 持仓收益 | 每一次「买入到全部卖出」的收益、持有天数、卖出原因 |
| 标的汇总 | 每只股票一共买过几次、胜率、合计盈亏 |
| 成交流水 | 每一笔成交的日期、方向、数量、价格、费用、原因 |

#### 5.2.3 AI 优化（「优化」按钮 / 「研究记录」标签）

点「优化 N 轮」后，AI 研究员会：

1. 阅读策略的完整报告（逐年表现、亏钱最多的持仓、卖出原因、各因子的历史表现、以往的研究笔记）；
2. 每轮提出几个改进方案（候选版本），每个只改 1～3 处，并说明理由；
3. 程序逐个回测并做严格检验（第 6.3 节），通过的才成为新冠军，没通过的写明原因。

在「研究记录」标签可以看到每一轮 AI 的诊断、提出的候选、检验结果、耗时和 token 用量，以及 AI 积累的**研究笔记**（可以手动编辑）。

> **请先读第 10 章**：实测 AI 修改单个策略的规则，挑出来的「更好版本」到了新行情里并不更好。严格的检验会把它们挡住，所以策略不会因此变差，但也很难靠这种方式变好。

「研究记录」顶部有三项**研究有效性**指标，专门回答「AI 优化到底有没有用」：

| 指标 | 怎么看 |
|---|---|
| 回测过拟合概率 PBO | 接近 50% = 挑「历史上最好的版本」和随便挑没区别；越低越好 |
| 开发期与留出期夏普的排名相关 | 开发期越好的版本留出期是否也越好；≤ 0 说明改进不能延续 |
| 滚动选择检验 | 每年年初只用之前的数据挑「当时最好」的版本，看它下一年表现。平均排名接近 50% 分位 = 和随机挑差不多 |

**研究设置**（设置菜单）：选择研究用的 AI 模型、回撤上限、显著性门槛、最少持仓数等。检验区间和本金在创建后不能改，否则各版本没法公平比较。

**手动编辑规则**：用表单（或 JSON）修改规则，可以先「试算」开发期再保存；保存后立即回测和检验，但不会自动替换冠军，需要时在「版本历史」里手动「设为冠军」。

**另存为新策略**（设置菜单，或版本详情里的按钮）：以当前冠军或任意一个版本为起点，另起一条独立的策略——原策略不受影响，新策略有自己的版本历史，可以手动修改、让 AI 优化、开始实时跟踪。可以选择是否复制研究笔记、用哪个研究模型、是否每晚自动优化。

- 检验区间、本金、升级门槛沿用原策略；原策略用的是旧的半时点股票池时，新策略改用全时点股票池并重新回测。
- 新策略会**继承原策略已经检验过的候选数和尝试次数**（策略页顶部会显示「另存自…继承已检验的候选 N 个」）。否则「另存一次就把次数清零」，就能绕开「试得越多门槛越高」的保护。

#### 5.2.3.1 AI 在交易中的角色

平台里 AI 有两种用法：

- **研究员**（上面的「优化」）：修改策略规则。实测效果很弱（见第 10 章）。
- **交易复核员**（第 5.3.1 节，组合页「AI 复核」）：每次调仓前逐只检查将要新买入的股票有没有重大风险，可以否决。它和纯规则账户并行运行、往后实时比较，用事实回答「AI 判断能不能让交易更好」。

#### 5.2.4 资金容量

回答「这个策略需要多少钱才玩得转、最多能放多少钱」。平台用 20 万到 10 亿共 10 档资金分别回测：

- **最低资金**：低于它，很多股票买不起一手（100 股），实际持仓和策略目标差太多，模拟结果就不可信了。
- **可承载资金**：超过它，买卖金额相对成交量太大，自己的买卖就会把价格推高 / 压低（冲击成本），收益明显下降。

你的实盘资金最好落在这两者之间。具体数字以「资金容量」标签为准：持仓越分散的组合，最低资金越高（五条风格策略组成的组合通常要上百万，三条的少一些）。

#### 5.2.5 信号与实时跟踪

- **最新信号**：按最近一个收盘日计算的目标持仓。输入你的资金量，会换算成每只股票买多少股、多少钱。
- **开始实时跟踪**：开一个模拟账户（见 2.5）。开始后这里显示：跟踪以来的收益和对照、净值曲线、最近的决策（含选股理由）、下一交易日的调仓清单、当前持仓。
- **对账与健康度**：
  - **对账**：用同样的规则做一遍快速回测，和模拟账户的实际记录比，确认「模拟交易执行得和回测一样」。结论分「一致 / 有偏差 / 偏差较大」。
  - **健康度**：把跟踪期的表现放到这个策略历史表现的分布里看，是不是明显差于以往。结论分「正常 / 关注 / 提醒」。「提醒」时会推送微信，表示策略可能失效或市场环境变了，建议复查。
- **回放校验**：选一个过去的日期，用模拟交易系统把那之后的行情重放一遍再对账。不用等几个月就能确认模拟系统本身没问题（约 400 个交易日需要 10 分钟左右）。

#### 5.2.6 可实盘检查

五项条件全部通过才标记「可实盘」，详见第 6.4 节。

#### 5.2.6.1 优化时间线

把这条策略从初始版本起的经历串成一条时间线，从新到旧排列：

- 每一轮 AI 优化：AI 的诊断（点开查看）和记下的经验；
- 每个候选：为什么改、和当时的冠军相比去掉了哪些规则（红色划线）、加上了哪些规则（绿色）、开发期夏普、月度配对检验的 p 值和累计测试次数、逐年跑赢冠军的年数，以及采纳与否的结论；
- 手动修改的版本；最下面是起点（初始规则；另存来的策略写明来源，新建前试算过的写明次数）。

只列开发期的结果：AI 研究和升级检验都只看开发期，留出期从不参与决定。勾选「只看有版本被采纳的」可以只看发生了升级的轮次。

#### 5.2.6.2 策略体检报告

策略详情右上角「…」菜单 →「策略体检报告」（查看公共策略时是右上角的按钮），在新标签页打开一页报告：基本信息、开发期与留出期表现、净值曲线、分年收益、过拟合检验（折算可信度、累计尝试次数、回测过拟合概率、开发期与留出期排名相关、滚动选择检验，每项都附解释）、当前规则、AI 优化过程（被采纳的改动和最近几轮）、可实盘检查（只有自己的策略才有），以及数据来源和免责声明。

报告是一个独立的网页文件：在浏览器里「另存为」就能离线打开、发给别人，不需要登录平台。

#### 5.2.6.3 导入导出策略

- **导出**：策略详情右上角「…」菜单 →「导出策略文件」（查看公共策略时是右上角的按钮），下载一个 `.stockarena.yaml` 文件，里面是冠军版本的规则、股票池、检验设置和测试历史，可以发给别人或提交到项目的 `community/strategies/` 目录。
- **导入**：策略库右上角「导入策略」，选择文件（或直接粘贴文件内容），可以改名。导入后是你自己的私有策略，会按本平台的数据和你的交易成本重新完整回测一次（十几秒到一分钟），所以结果可能和对方的不一样；差别较大时会提示。
- 文件里的测试历史会继承下来：对方已经试过多少个候选，导入后的升级门槛和折算可信度都会算进去。策略页上会一直标注「从策略文件导入」及原策略名和版本。

#### 5.2.6.4 用 AI 客户端连接（MCP）

「配置中心 → MCP 接入」可以新建个人 API 令牌，让 Claude Code、Cursor 等 AI 客户端连上平台：在对话里让它查你的策略、解释某次优化改了什么、试算一个想法；令牌勾选「允许修改」后，它还能新建策略、提交新版本、启动 AI 优化。

- 页面会生成现成的配置命令，复制到客户端即可；令牌只显示一次。
- 和网页一样只能看到自己的策略和公共策略。为了不让 AI 按留出期挑策略，MCP 只提供开发期结果，留出期请在网页上看。
- 让 AI 试算的次数也会计入测试次数。
- 不用了就在同一页「撤销」。详见 [MCP.md](MCP.md)。

#### 5.2.7 版本历史

所有回测过的版本：状态（冠军 / 淘汰……）、来源（AI / 手动）、开发期夏普和回撤、相对冠军的超额和 p 值、留出期收益、检验结论。点开可以看完整报告和交易明细，也可以「设为冠军」或「以此为基础编辑」。

### 5.3 多风格组合

左侧是组合列表，右侧是选中组合的详情。

- **新建组合**：选 2～10 条策略（必须用同一个股票池），设权重（会自动换算成合计 100%）。还可以选资金配置方法（固定权重 / 波动率倒数 / 风险平价 / 目标波动），但实测都没比固定权重好，建议用固定权重。
- **回测报告**：组合在开发期和留出期的表现、各成员的表现、成员之间的相关性（越低越分散）。
- **资金容量**、**信号与实时跟踪**、**可实盘检查**：和单个策略相同。
- 组合在**同一个账户**里运行：每个成员按自己的节奏调仓，任一成员调仓时，整个账户回到目标比例。

#### 5.3.2 自选倾斜（按你的偏好调整，和原组合并行比较）

组合页的「自选倾斜」标签，开启后多一个「自选倾斜账户」，和纯规则账户在同一个赛道、本金相同、同一天调仓：

- 每次调仓，把规则的目标仓位乘以你的自选权重（不在自选股里的都是 1），再按比例缩放回原来的总仓位。
- **只调整策略已经选中的股票，不会买入策略没选中的**。权重 0 = 不买也不持有（钱分给其他选中的股票）；大于 1 = 多配，单只最多是原仓位的 3 倍、且不超过 10%。
- 两条净值的差就是你的偏好带来的加分或减分。权重改动在下一次调仓时生效。
- 你的偏好是现在才有的，不能拿去回测历史（那等于用了后见之明），所以只能从开启之后实时比较。现有的纯规则账户和 AI 复核账户不受影响。

#### 5.3.1 AI 复核（规则 + AI 复核，两个账户并行）

组合页的「AI 复核」标签：

- **怎么运作**：开启后，平台为这个组合多开一个「AI 复核账户」，和原来的「纯规则账户」本金相同、在同一个赛道里并行。每次调仓，两个账户的计划完全一样；区别只在于 AI 复核账户会先让 AI 逐只看一遍**将要新买入**的股票——最近 30 天的公告、最近的新闻、近期走势——发现明确的重大风险（立案调查、退市风险、业绩暴雷、大股东大额减持等）就**否决**，这只股票不买、钱留在现金里。短期涨跌、估值高低这类判断不归 AI 管（规则已经处理了）。
- **怎么看结果**：
  - 两条净值曲线：「规则 + AI 复核」与「纯规则」，差距就是 AI 带来的加分或减分；
  - 「被否决股票之后的超额」与「被放行股票之后的超额」：被否决的股票之后明显跑输，说明 AI 否决得对；
  - 复核记录：每只股票的结论、风险等级和理由（会引用具体公告或新闻）。
- **调仓提醒**里也会附上当天的 AI 复核意见。你实盘时可以参考：照规则全部买入，或者跳过 AI 否决的股票。
- **需要多久才有结论**：否决本来就少（AI 只在明确重大风险时出手），至少要积累几十次否决、几个月时间，差异才不是运气。在那之前页面上的数字只是展示，**不要据此下结论**；最好像下面这样事先写好判断标准（「预注册」，见名词解释）再看结果。
- **有效性评估卡片**：项目作者在 2026-10-08 为自己的两个组合写过一份预注册（`docs/prereg/2026-10-08-ai-review.md`，第 120、250 个交易日各评估一次），页面上的「有效性评估」卡片只对那两个组合显示。你自己的部署可以参照它的写法，为自己的组合写一份。
- **评估期间尽量不改配置**：换复核模型、给 AI 装新技能、启用已停用的技能，都会让前后数据不能合在一起比较。
- **模型要能用**：复核在每个交易日收盘后（约 15:45 起）调用你选择的模型；用本地模型时需要模型服务在运行。模型调用失败时当天按规则执行，不影响纯规则账户。

### 5.5 实盘对照

开始用真钱交易后，在这里记录并核对：

1. **新建实盘账户**：选择跟随的策略或组合、初始资金、开始日期；之后有资金转入转出可以补记。
2. **录入成交**：
   - 手工录入：日期、代码、买 / 卖、数量、价格、费用；
   - 或**导入券商成交明细**：在券商软件里导出「历史成交」为 CSV 文件，点「导入券商成交明细（CSV）」。会先预览识别结果，确认后再导入；重复的记录自动跳过，红利入账等非买卖记录会跳过并说明原因。
3. **对比报告**：
   - 实盘和模拟的收益、收益差、跟踪误差、两条净值曲线；
   - **执行对照**：逐笔把实盘成交和模拟成交配对，算出平均成交价差（正数 = 你买得比模拟贵 / 卖得比模拟便宜）、因此损失的金额、平均晚了几天；
   - **漏做**（模拟做了、你没做）和**多做**（你做了、模拟没做）的交易；
   - 结论：一致 / 有偏差 / 偏差较大。

平台**不连接券商**，不需要、也不保存任何券商账号或密码，只保存你提供的成交数据。

### 5.6 因子研究

**因子**就是给股票打分用的指标（比如市盈率、过去 60 天涨幅）。这一页回答「某个指标过去到底能不能挑出更会涨的股票」：

| 列 | 意思 | 怎么看 |
|---|---|---|
| 平均 IC | 指标高低和之后 20 天涨跌的相关程度 | 绝对值越大越有用；0.03～0.05 已算不错 |
| t 值 | 这个相关是不是靠运气 | **绝对值 ≥ 2 才算比较可靠** |
| 逐年 IC | 每年的表现 | 正负来回翻转说明时灵时不灵 |
| 五分组年化 | 按指标从低到高分 5 组，各组的年化收益 | 看组和组之间有没有明显的阶梯 |
| 多空年化 | 最好一组减最差一组 | |

可以切换开发期 / 留出期、股票池（沪深300 / 中证800）。实测沪深300 范围内几乎没有特别强的单个指标，这也是单靠改规则很难提升的原因之一。

#### 5.8.6 技能（扩展 AI 能查询的资料；管理员）

「配置中心 → 技能」（技能功能默认关闭，需要部署的人在配置里打开，见 [SKILLS.md](SKILLS.md)；没打开时看不到这个标签）。**技能**是别人做好的「说明书 + 小工具」包，比如腾讯自选股的金融数据查询。安装后，AI 复核员在需要时会自己阅读说明、调用它查资料（公告全文、业绩预告、资金流向等）。

- **安全规则：AI 可以找、可以用，但每次安装都要你批准。** 技能在一个隔离的「小房间」（沙箱）里运行：看不到平台的数据和密钥，只能访问你允许的网址，不能直接上网，也碰不到局域网里的其他设备。
- **怎么安装**：
  1. 第一次使用先点「初始化沙箱」（几分钟，只需一次）；
  2. 三种来源：在「技能市场」搜索后点「获取并审阅」、填 GitHub 地址、或上传 zip；
  3. 审阅页会列出包里的所有文件（脚本可以点开看）、要访问的网址、风险提示。确认「允许访问的域名」「AI 可调用的命令」「仅限本人的子命令」后点「批准安装」；
  4. 需要登录 / 授权的技能（如腾讯自选股）：安装后点「终端」，执行它的授权命令（如 `westock auth status`），按提示在浏览器里完成授权，再回到**同一个终端窗口**执行 `westock auth fetch`，看到 `TOKEN_READY` 就完成了。同一个终端窗口里的命令在同一个隔离环境中执行，关闭窗口（或闲置 15 分钟）后环境销毁，所以授权要在一个窗口里做完。**密钥只在你自己的操作里出现，不要交给 AI。**
- **AI 自己找技能**：AI 复核员觉得资料不够时，会去技能市场搜索并「提交申请」，说明为什么需要。你会收到微信推送（「技能申请」），在技能页审阅后批准或拒绝。不想让 AI 申请，可以关掉页面上的开关。
- **出了问题怎么查**：每个技能的「详情」里有调用记录（谁调用、命令、结果、被拦截的网址）。如果某个技能总是被拦截，说明它需要访问的网址没在允许列表里，确认可信后加上即可。
- 社区技能质量参差不齐（有的会偷偷下载程序、有的涉及下单交易），**宁可不装，也不要不看就批准**。

### 5.9 系统状态（管理员）

- **服务**：后端是否正常、数据库、定时任务调度器是否在运行。
- **数据源**：行情、财报、分红数据最近一次成功 / 失败的时间。
- **数据质量**：每晚自动扫描行情数据里可能导致「假收益」的错误：

  | 类型 | 意思 |
  |---|---|
  | 异常跳变 | 某天涨跌幅超过了涨跌停限制——正常交易不可能出现，多半是数据或复权出错 |
  | 价格不一致 | 比如最高价比收盘价还低 |
  | 复权因子 | 复权因子异常下降 |
  | 长期无行情 | 连续 60 个交易日以上没有数据（长期停牌或数据缺失） |
  | 未更新 | 还在股票池里，但最近几天没有数据（停牌或数据源没更新） |

  每条可以「**重新下载**」该股票的数据（下载后自动重新回测并重新扫描），确认是真实情况的可以「**忽略**」。级别：错误（红）> 提示（黄）> 参考（灰）。
- **调度任务**：定时任务和下次运行时间。
- **最近事件**：系统运行日志。

## 6. 怎么读懂结果

### 6.1 常用指标速查

| 指标 | 白话解释 | 怎么看 |
|---|---|---|
| 累计收益 | 这段时间一共赚了百分之几 | 100 万变 130 万就是 +30% |
| 年化收益 | 折算成平均每年赚多少 | 3 年累计 +33.1% ≈ 年化 +10% |
| 基准 / 超额收益 | 基准是用来比较的对象（默认沪深300 指数）；超额 = 策略收益 − 基准收益 | 超额为正才说明比「直接买指数」强 |
| 波动率 | 收益上下起伏的剧烈程度 | 越高越颠簸。沪深300 一般在 20% 左右 |
| **最大回撤** | 从某个最高点跌到之后最低点的最大幅度 | 例如从 120 万跌到 90 万，回撤 25%。**这是实盘中最可能让人拿不住的数字**，先问自己能不能承受 |
| **夏普比率** | （年化收益 − 2%）÷ 波动率：每承受一份颠簸换来多少收益 | 0.5 一般，1 以上相当好。比只看收益更公平 |
| 卡玛比率 | 年化收益 ÷ 最大回撤 | 越高越好 |
| 年化换手 | 一年买卖的金额是平均资产的几倍 | 越高手续费越多、对成交价越敏感 |
| 胜率 | 每次完整持有中，赚钱的比例 | 趋势类策略胜率低（常常 40% 以下）但赚的时候赚得多，属正常 |
| 稳健性 | 规则里的数字随机改动 ±20% 后，夏普还剩原来的百分之几 | 越接近 100% 越好；很低说明结果依赖「凑巧的参数」 |

### 6.2 为什么要分三段时间看

AI 和人都能看到开发期的数据，反复修改规则就一定能让开发期越来越好看——但那可能只是「背下了历史答案」。**留出期**从来不参与修改，是诚实的考试成绩；**实时跟踪**用的是选中之后才发生的行情，更加无法作弊。

挑选建议：

- 留出期明显比开发期差很多的，要警惕；
- 版本号新不代表更好；
- 最终以实时跟踪为准。

### 6.3 新版本凭什么能取代冠军（升级标准）

候选版本要**同时满足**以下全部条件：

1. **开发期夏普高于冠军**；
2. **大多数年份更好**：把两者调到相同的波动水平后，开发期 7 年里至少一半年份跑赢冠军（防止靠某一年运气）；
3. **统计上显著**：月度超额收益不是偶然的。p 值要小于 0.05 ÷ 「这个冠军以来已经试过的候选数」——试得越多，门槛越严（见第 9 章「多重检验」）；
4. **风险可控**：最大回撤不超过 25%、年换手不超过 20 倍、股票策略至少持有 20 只；
5. **稳健**：参数随机改动 ±20% 后，夏普至少保留 70%。

### 6.4 「可实盘」五项检查

| # | 条件 | 白话 |
|---|---|---|
| 1 | 开发期夏普高于基准 | 历史上风险调整后比买指数强 |
| 2 | 留出期夏普高于基准，且不低于开发期的一半 | 考试也考过了，没有明显退化 |
| 3 | 开发期完整年份中至少一半跑赢基准 | 不是靠一两年撑起来的 |
| 4 | 实时跟踪满 60 个交易日，健康度不是「提醒」，对账不是「偏差较大」 | 在全新行情里也正常 |
| 5 | 计划资金在「最低资金」和「可承载资金」之间 | 你的资金规模适合这个策略 |

- 第 4 条需要时间，在那之前显示「**待观察**」；任何一条不满足显示「**未通过**」；全部满足显示「**可实盘**」。
- 每晚自动重新检查；结论变化时推送微信。
- 「可实盘」只代表模拟检验全部通过，**不保证将来赚钱**。

### 6.5 健康度与对账

| 结论 | 对账（模拟执行得和回测一不一致） | 健康度（表现是不是明显差于以往） |
|---|---|---|
| 好 | 一致 | 正常 |
| 中 | 有偏差 | 关注：部分指标处于历史偏弱区间，继续观察 |
| 差 | 偏差较大：先查是不是数据或系统问题 | 提醒：明显差于历史，策略可能失效或市场环境变了，建议复查 |

健康度主要看两点：最近一段时间（最多 60 个交易日）的收益在历史同长度收益中排在多少分位（低于 5% 分位为「提醒」）；跟踪期最大回撤是否超过历史最大回撤的 1.2 倍。

```
- 买入 600036 招商银行 1000 股 × 40.12 ≈ 40,120 元
- ……
金额按收盘价估算；实盘请按自己的持仓与资金核对后下单。
```

- 「依据 09-30 收盘」：根据那天收盘后的数据做的决定；
- 「10-08 开盘执行」：模拟账户在这天开盘按开盘价成交；
- 股数是按**模拟账户**（100 万）算的。你的资金不同，按比例换算（或在详情页「最新信号」里输入自己的资金量直接算股数）；
- 「参考价」是前一天的收盘价，开盘价会有出入。

### 7.2 下单要点

1. **先卖后买**：卖出回笼的钱用来买入，和模拟一致。
2. **尽量在开盘附近成交**：模拟按开盘价成交，越接近开盘，和模拟越接近。
3. **按整手（100 股）**：科创板股票 200 股起买、之后可以按 1 股递增，以券商规则为准。
4. **涨停买不进、跌停卖不出、停牌不能交易**：模拟也同样处理，买不到不必强求，下次调仓会重新计算。
5. **对照自己的持仓**：如果你某次没按提醒做，之后的清单（按模拟账户算）和你实际需要的买卖会有差别，以「目标持仓 − 你的实际持仓」为准。
6. **记录成交**：定期从券商导出成交明细，导入「实盘对照」，看执行偏差（第 5.5 节）。

### 7.3 资金量与「最低资金」

资金低于组合的「最低资金」时，很多股票买不起一手，实际持仓会和模拟差很多。可以选持股更少的组合（例如三风格稳健最低约 20 万），或者先只跟踪不实盘。

## 8. 常见问题

**Q：为什么今天没有收到调仓提醒？**
A：可能是：①今天不需要调仓（大多数日子都不调）；②还没配置推送通道，或通道停用了——去「配置中心 → 消息推送」看状态，「最近推送」里有失败原因；③非交易日；④数据延迟——21:00 还没完成会收到异常提醒。

**Q：调仓清单里为什么有「权重调整：加仓 / 减仓」的小额订单？**
A：组合的各成员调仓节奏不同，某个成员调仓时整个账户会回到目标比例。金额差小于净值 0.5% 的调整会被跳过，以减少零碎订单。

**Q：AI 优化了很多轮，冠军一直没变，是不是坏了？**
A：不是。升级标准很严（第 6.3 节），而且试得越多门槛越高。实测大部分候选都过不了，这正是在防止过拟合。见第 10 章。

**Q：AI 优化要花钱吗？**
A：用本地模型不花钱，但占用显卡；用云端模型按 token 计费。作者的实测：本地 27B 模型每轮 1.5～4 分钟，DeepSeek 每轮约 0.05 元、0.5～1.5 分钟。「研究记录」里有每轮的 token 用量。

**Q：回测收益为什么和我看到的旧数字不一样了？**
A：修改交易成本、修复数据错误、程序升级成本算法之后，所有在用策略会自动重新回测，数字会更新。新数字更接近真实。

**Q：为什么留出期比开发期差那么多？**
A：常见原因：开发期的规则多少「贴合」了那段历史（过拟合）；市场风格变了；历史数据有幸存者偏差（第 10 章），开发期本身就偏乐观。所以要以留出期和实时跟踪为准。

**Q：「数据质量」里有一堆「参考」级别的「长期无行情」，要处理吗？**
A：一般不用。多数是历史上的长期停牌（2017～2018 年很常见）。重点看红色的「错误」。

**Q：手机能用吗？**
A：用手机浏览器打开同一个网址即可；页面主要为电脑设计，手机上看表格要横向滑动。

**Q：在外面能访问吗？**
A：取决于部署方式。默认只在局域网里能访问；需要在外网使用时，请按 [DEPLOY.md](DEPLOY.md) 第 4 节放在 HTTPS 反向代理后面，不要直接把端口暴露到公网。

**Q：页面显示「后端未连接」或打不开？**
A：服务器可能关机或服务停了。能登录服务器的人可以查看服务状态并重启：Docker 部署用 `docker compose ps`、`docker compose restart`；systemd 部署用 `systemctl --user status stockarena`、`systemctl --user restart stockarena`。

**Q：忘记登录密码？**
A：见第 3.1 节。

## 9. 名词解释

按主题分组。

### 9.1 市场与交易

| 名词 | 解释 |
|---|---|
| A股 | 在上海、深圳、北京证券交易所上市、用人民币交易的股票 |
| 主板 / 创业板 / 科创板 | A股的不同板块。主板涨跌停 10%；创业板（代码 30 开头）和科创板（688 开头）涨跌停 20%，波动更大 |
| ETF | 交易所交易基金：一篮子股票（或债券、黄金）打包成一只基金，像股票一样买卖。如沪深300ETF 就是一次买下沪深300 的 300 只股票 |
| LOF | 上市型开放式基金，也能在交易所买卖，和 ETF 类似 |
| 指数 | 衡量一组股票整体涨跌的数字，如沪深300 指数。指数本身不能直接买，可以买跟踪它的 ETF |
| 沪深300 | 沪深两市规模最大、交易最活跃的 300 只股票组成的指数，代表大盘蓝筹 |
| 中证800 | 沪深300 + 中证500，共 800 只，覆盖大中盘股 |
| 成分股 | 某个指数包含的股票 |
| 申万一级行业 | 申万宏源的行业分类，共 31 个一级行业（银行、医药生物、电子……） |
| ST 股 | 因连续亏损等原因被「特别处理」的股票，风险高，涨跌停 5%。平台的策略通常排除它们 |
| 涨停 / 跌停 | 单日涨跌幅上限。到了涨停价通常很难买到，到了跌停价很难卖出 |
| 停牌 | 股票暂停交易，期间不能买卖 |
| 一手 / 整手 | A股买入的最小单位是 100 股（一手），只能按 100 股的整数倍买 |
| T+1 | 今天买的股票明天才能卖 |
| 开盘价 / 收盘价 | 当天第一笔 / 最后的成交价格 |
| 集合竞价 | 开盘前 9:15～9:25 集中撮合决定开盘价的时段 |
| 佣金 | 券商收的交易手续费，买卖都收，按金额的万分之几，有最低收费（常见 5 元） |
| 免五 | 券商免除「最低 5 元」的规定，小额交易更省钱 |
| 印花税 | 国家收的税，A股只在**卖出**时收 0.05%（2023 年 8 月 28 日之前是 0.1%）；ETF 免收 |
| 过户费 | 股票买卖时收的 0.001%，ETF 免收 |
| 红利税 | 拿到现金分红时扣的个人所得税，按持股时间：1 个月以内 20%，1 个月～1 年 10%，超过 1 年免征；ETF 分红免税 |
| 分红 / 派息 | 公司把利润以现金分给股东 |
| 送转股 | 公司按比例给股东增加股数（比如 10 送 10），股价相应降低，总价值不变 |
| 除权除息 | 分红或送股的那天，股价会相应下调（不是真的跌了） |
| 份额折算 / 拆分 / 合并 | 基金把 1 份拆成几份（价格变低）或几份合成 1 份（价格变高），总价值不变 |
| 复权 / 复权因子 | 把除权除息造成的「假涨跌」修正掉，让价格前后可比。复权因子就是做这个修正用的系数。复权出错会制造假的暴涨暴跌，导致回测出现假收益 |
| 滑点 | 实际成交价和预想价格的差。平台按开盘价 ± 0.05% 估计 |
| 冲击成本 | 买卖金额大时，自己的交易会把价格推高（买）或压低（卖）造成的额外成本。资金越大越明显 |
| 流动性 / 成交额 | 一只股票每天成交多少钱。成交额小的股票，大资金难进出 |
| 实盘 | 用真钱在券商账户里交易 |

### 9.2 策略与组合

| 名词 | 解释 |
|---|---|
| 量化策略 | 用明确的数字规则决定买卖，而不是凭感觉 |
| 风格 | 策略的投资思路：价值投资（买便宜的好公司）、趋势跟随（买正在涨的）、均值回归（买跌多了可能反弹的）、ETF 轮动（在几只 ETF 之间切换）、防御稳健（低波动、高股息）、指数择时（根据大盘状态加减仓）、质量成长（买盈利能力强、增长快的） |
| 股票池 | 策略可以从中挑选的股票范围，如「沪深300（全时点）+ 核心 ETF」 |
| 因子 | 给股票打分的指标，如市盈率倒数（越便宜分越高）、过去 60 天涨幅（动量）、波动率。策略按几个因子的综合分挑股票 |
| 综合排名 | 把几个因子的分数加权平均后，在所有可选股票中的名次 |
| 行业中性 | 只在同一个行业内比较排名，避免一下子全买某一个行业 |
| 调仓 | 按规则重新计算目标持仓并买卖。平台的策略一般每 5～20 个交易日调一次 |
| 再平衡 | 把各部分的比例拉回目标（比如某只股票涨多了占比过高，卖掉一些） |
| 权重 | 某只股票（或某条策略）占总资金的比例 |
| 等权 | 每只股票分一样多的钱 |
| 止损 | 从买入价跌到一定幅度就卖出 |
| 移动止损 | 从持有期间的最高点回落到一定幅度就卖出（保护已有的盈利） |
| 择时 | 根据大盘状态决定仓位高低，比如指数跌破均线就减仓、把钱放到国债 ETF |
| 仓位 | 买了股票的钱占总资金的比例。满仓 = 全部买成股票 |
| 多风格组合 | 把钱分给几条不同风格的策略一起运行，降低单一风格失灵的风险 |
| 资金配置方法 | 组合内怎么分钱：固定权重；波动率倒数（波动大的少分）；风险平价（让各成员贡献的风险相同）；目标波动（整体波动太大时降仓位） |
| 版本 / 冠军 / 候选 | 规则每改一次是一个版本；当前正式使用的是冠军；等待检验的新版本是候选 |
| 研究模型 | 负责提出改进方案的 AI 模型（云端或本地模型，在「配置中心 → 模型供应商」添加） |
| 技能（Skill） | 别人做好的「说明书 + 小工具」包，安装后 AI 可以按需阅读、调用，用来查询更多资料 |
| 沙箱 | 隔离的运行环境：里面的程序看不到外面的数据、只能访问允许的网址，出了问题也影响不到平台 |
| AI 复核 / 复核员 | 调仓前由 AI 逐只检查将要新买入的股票，有重大风险时否决；与纯规则账户并行比较效果 |
| 孪生账户 / 对照账户 | 除了要比较的那一个因素（这里是 AI 否决）之外完全相同的两个模拟账户，用来干净地衡量这个因素的作用 |
| token | AI 模型处理文字的计量单位，云端模型按 token 收费 |

### 9.3 检验与统计

| 名词 | 解释 |
|---|---|
| 回测 | 把策略放到历史行情里模拟执行，看当年的结果 |
| 模拟交易 / 实时跟踪 | 用每天的新行情、虚拟资金按策略交易 |
| 回放校验 | 用模拟交易系统把一段历史重新跑一遍，确认它和回测结果一致 |
| 对账 | 比较模拟账户的实际记录和同期回测，确认执行没走样 |
| 跟踪误差 | 两条收益曲线每天差异的波动程度（年化），越小越一致 |
| 开发期 / 训练 / 验证 | 允许反复研究和修改规则的历史区间（默认 2018～2024，前 5 年是训练，后 2 年是验证） |
| 留出期 / 样本外 | 从不参与修改规则的区间（2025 年至今），用来诚实检验 |
| 样本内 | 研究时看过的数据 |
| 预注册 | 在看到结果之前，先把「怎么检验、什么算通过、不通过怎么办」写下来并提交存档，之后照着执行、不再修改。防止看到数据后挑对自己有利的说法 |
| 置换检验 | 把「否决 / 放行」这类标签随机打乱很多次，看打乱后的差距有多少次比实际还大；比例很小，说明实际差距不太可能是碰巧 |
| 过拟合 | 规则过度贴合历史的偶然细节——像背下了考试答案，换一套题就不会。回测漂亮、实际失灵的头号原因 |
| 前视偏差 | 回测中不小心用到了「当时还不知道的信息」（比如用年底才公布的年报做年初的决策），会让回测虚高。平台按法定披露截止日使用财报来避免 |
| 幸存者偏差 | 只用「现在还在」的股票做回测，漏掉了中途退市或被踢出指数的差股票，结果偏乐观 |
| 全时点股票池 | 每个历史日期只允许选当天真实在指数里的股票，包括后来被剔除、已经退市的股票，消除幸存者偏差。策略工坊默认使用（如「沪深300（全时点）+ 核心ETF」）。旧的「半时点」股票池只知道当前成分的纳入日期、缺少被剔除的股票，只保留作对比 |
| 基准 | 用来比较的对象，默认是沪深300 指数 |
| 超额收益 | 策略收益减去基准收益 |
| 贝塔 | 策略跟随大盘涨跌的程度。1 表示和大盘同步，0.8 表示大盘涨 10% 它约涨 8% |
| 相关性 | 两个东西是否同涨同跌，范围 −1 到 1。组合成员之间相关性越低，分散效果越好 |
| 分位 / 百分位 | 在一组数中的位置。「前 5%」= 排在最好的 5% 里；「5% 分位」= 比 95% 的情况都差 |
| IC（信息系数） | 因子分数和之后涨跌的排名相关程度，衡量因子的选股能力 |
| ICIR | IC 的平均值除以它的波动，衡量因子是否稳定有效 |
| t 值 | 结果有多大可能不是运气。绝对值 ≥ 2 一般认为比较可靠 |
| p 值 / 显著性 | 「如果其实没有真本事，纯靠运气得到这么好结果」的概率。p 越小越可信；平台要求 p ≤ 0.05 再按检验次数收紧 |
| 多重检验 | 试的次数越多，越容易碰巧撞到一个「看起来很好」的结果。所以试了 n 个候选，门槛就要收紧到原来的 1/n |
| bootstrap（自助法） | 把历史数据反复随机重抽来估计「靠运气能达到什么程度」的统计方法，用来算 p 值 |
| 等波动换算 | 把两个策略调到相同的波动水平再比较收益，避免「只是更激进」被当成「更好」 |
| 稳健性检验 | 把规则里的数字随机改动 ±20% 再回测，看结果是否仍然成立 |
| 折算可信度（DSR） | 考虑到尝试次数后，冠军的真实夏普大于 0 的概率 |
| PBO（回测过拟合概率） | 反复把历史切成两半，用一半挑最好的版本，看它在另一半里是否落到中位数以下；这个比例就是 PBO。约 50% 说明挑选等于随机 |
| 排名相关 | 两组排名的一致程度：开发期排名靠前的版本，留出期是否也靠前 |
| 滚动选择检验（walk-forward） | 每年年初只用之前的数据挑版本，看它下一年的表现，逐年滚动。模拟「当时的你」会怎么选 |
| 资金容量 / 最低资金 / 可承载资金 | 策略适合的资金范围：太少买不全目标持仓，太多冲击成本过大 |
| 持仓偏离 | 调仓后实际持仓和目标持仓差了多少（没按目标配置的资金比例） |
| 健康度 | 跟踪期表现和历史表现相比是否正常 |

## 10. 现状与局限（请务必读）

截至 2026 年 10 月，项目作者在自己的部署上做的研究得出了以下结论（你的部署从同样的初始策略开始，结论应当相近），请据此调整期望：

1. **AI 修改单个策略的规则，在样本外没有带来可靠的提升。** 换过两个 AI 模型（本地 Qwen、DeepSeek）、两个股票池（沪深300、中证800）、新旧共 29 个因子，结果一致：回测过拟合概率 0.57～0.83，开发期和留出期的排名相关 ≤ 0.1，滚动选择检验中挑出的版本和随机挑差不多。严格的升级标准会把这些「伪改进」挡住，策略不会被改坏，但也很难被改好。
2. **单个选股指标都比较弱**，在沪深300 范围内几乎没有特别可靠的因子。
3. **组合层的资金配置方法**（波动率倒数、风险平价、目标波动）也没有比固定等权更好。
4. **目前证据最充分的选择是等权的多风格组合**。作者的两个组合（五风格均衡、三风格稳健）从 2026-10-08 开始实时跟踪，要跟踪满 60 个交易日才能给出「可实盘」的判断；你自己的组合也一样，从开始跟踪起算。**在此之前的结论都只是历史回测。**
5. **幸存者偏差已基本消除（2026-10-09）**：以前的股票池缺少历史上被剔除和已退市的股票，2018～2024 年「把可选股票每只买一样多」年化约 10%，而同期指数接近 0。改用全时点股票池后这个数字降到 1.2%；选股策略开发期年化普遍下降 1～4 个百分点，两个组合下降 1～2 个百分点，留出期基本不变。历史成分按月更新，纳入 / 剔除日期仍有约一个月的误差。
6. **AI 模型可能「见过」留出期的行情**：AI 训练时可能读到过 2025 年的市场信息，所以留出期也不是完全「未知」，实时跟踪才是最干净的检验。
