# 数据源说明

StockArena 不提供、不分发任何数据。所有数据都由**你自己的部署**在运行时从第三方公开接口获取，大部分通过 [AKShare](https://github.com/akfamily/akshare) 调用，
保存在本地数据库和 `data/cache/` 里。这些接口不属于本项目，可能随时改版、限流或停止服务；请遵守各网站的使用条款，只用于个人学习研究（见 [免责声明](../DISCLAIMER.md)）。

## 1. 每个数据源用在哪里

### A 股（策略工坊的主要数据）

| 数据 | 来源 | 用在哪里 |
|---|---|---|
| 股票日线（不复权）、后复权因子、分红送配 | 新浪财经 | 回测、实时跟踪、信号；**腾讯财经**作为日线备用源 |
| ETF / LOF 日线与分红 | 新浪财经 | ETF 轮动等策略、核心 ETF |
| 指数日线 | 新浪财经 | 基准、大盘择时 |
| 交易日历 | 新浪财经 | 日终流程、回测日期 |
| 股票代码与简称 | 交易所（经 AKShare） | 股票名称 |
| 指数当前成分 | 中证指数公司 | 股票池（最新一次快照之后的成分） |
| 指数历史成分（每月快照）、已退市股票的行情与复权因子、上市 / 退市日期 | Baostock | 时点股票池（减少幸存者偏差），只在「准备数据」和每晚检查有没有新的月度快照时使用 |
| 申万行业分类及变更记录 | 巨潮资讯 | 行业中性、同一行业持仓上限、行业工具 |
| 财报摘要（ROE、增速、毛利率等） | 同花顺 | 基本面因子；按法定披露截止日判断何时可用，避免前视偏差 |
| 上市公司公告 | 巨潮资讯 | AI 交易复核、自选股监控 |
| 个股新闻 | 东方财富 | AI 交易复核、自选股监控、AI 对比 |
| 实时行情 | 腾讯财经 | 首页、股票详情、盘中价格展示 |
| 股票搜索 | 腾讯财经 | 搜索框 |
| 涨跌家数 | 乐咕乐股 | 首页市场概览 |

## 2. 什么时候会去拉数据

| 时间（北京时间，交易日） | 做什么 |
|---|---|
| 第一次「准备数据」 | 下载股票池的历史成分、2016 年以来的行情、财报、行业分类，约 20～30 分钟 |
| 收盘后（15:45 起，A 股） | 更新当天行情，实时跟踪账户结算和下单，生成信号 |
| 19:30 | 每晚数据更新（增量；顺带检查 Baostock 有没有新的月度成分快照，已有的月份不重复查）、数据质量扫描、AI 优化（如果开启） |
| 21:15（每天） | 自选股监控：拉公告、新闻和异常波动（如果有自选股） |

所有请求都有限速（同一数据源两次请求之间至少间隔零点几秒）和失败重试（指数退避），尽量不给数据源造成压力。

## 3. 数据拉不下来怎么办

1. **看哪个数据源出错**：「系统状态 → 数据源」显示各数据源最近一次成功 / 失败的时间；后端日志（`data/logs/`，Docker 部署用 `docker compose logs`）里有具体报错，日志里的名字对应上表，例如 `sina.daily.600519.SH`、`cninfo.industry.000001`。
2. **网络和代理**：
   - 国内行情网站经代理访问很容易被断开。程序启动时会把这些域名加入 `NO_PROXY` 自动直连（配置项 `direct_hosts`，见 [CONFIG.md](CONFIG.md)）。如果你的网络环境需要别的直连域名，加到这个列表里。
   - 服务器在境外时，部分国内接口可能很慢或拒绝访问。
3. **暂时性故障**：免费接口偶尔会限流或维护，一般过一会儿自动恢复；第二天的日终流程会补上缺的数据。
4. **接口改版**：如果某个数据源持续报错（比如报字段不存在），多半是网站改版了。先把 AKShare 升级到最新版（`cd backend && uv lock --upgrade-package akshare && uv sync`），还不行就提一个「数据源问题」Issue，写明数据源、股票、日期和报错。
5. **Baostock 很慢或断线**：Baostock 登录要几十秒，之后每次查询约 1 秒；服务器断开时会自动重新登录并重试。如果最终还是失败，全时点股票池就缺历史成分，只剩今天的成分。这时策略库会显示黄色警告，这些策略的「可实盘检查」也会判为未通过，避免带着幸存者偏差而不自知。已经查到的月份有缓存，点「重新准备完整数据」只补缺的部分。它只在准备数据和每晚检查新月份时使用，出错不影响当天的行情更新和交易。

## 4. 数据不对怎么办

- **数据质量扫描**：每晚自动检查行情里可能导致「假收益」的错误（超过涨跌停的跳变、最高价低于收盘价、复权因子异常、长期没有行情等），结果在「系统状态 → 数据质量」，每条都可以「重新下载」或确认后「忽略」。
- **复权**：回测用不复权价格加后复权因子计算收益，分红送转按除权日处理。发现某只股票的收益明显异常时，先在数据质量里重新下载它的数据。
- **成分股日期**：Baostock 的成分快照按月更新，纳入 / 剔除日期和中证指数公司的正式调整日最多相差约一个月（研究记录见 [research/2026-10-08-pit-universe.md](research/2026-10-08-pit-universe.md)）。
- **财报可用日期**：财报按法定披露截止日之后才算「可用」（一季报 4/30、半年报 8/31、三季报 10/31、年报次年 4/30），宁晚勿早，避免用到当时还没公布的数据。
