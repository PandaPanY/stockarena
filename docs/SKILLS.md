# 技能（Skills）

**技能**是别人做好的「说明书 + 小工具」包（目录里有一个 `SKILL.md`），比如某个金融数据查询工具。安装后，AI 复核员和自选股监控在需要时可以阅读说明、调用工具，查到更多资料（公告全文、业绩预告等）再做判断。

技能会在你的机器上**执行第三方代码**，所以：

- 默认**关闭**，需要你在配置里明确打开；
- 只有管理员能安装、审批、使用；
- 每个技能都在隔离的 Docker 容器里运行，网络只能访问它声明并经你批准的域名。

> 不打开技能，平台的其他功能（回测、组合、模拟、AI 优化、AI 复核、自选股监控）都照常可用，只是 AI 不能调用技能查资料。

## 1. 打开技能功能

### 运行要求

| 项目 | 要求 |
|---|---|
| 部署方式 | **直接运行**（见 [DEPLOY.md](DEPLOY.md) 第 3 节）。Docker 部署方式下需要在容器里再运行 Docker，暂不支持 |
| 系统 | Linux（只在 Linux 上测试过；沙箱用到 Docker 内部网络和主机网络模式） |
| Docker | 已安装，并且运行 StockArena 的用户能执行 `docker` 命令（在 `docker` 用户组里） |
| 网络 | 初始化沙箱时要下载 `debian:bookworm-slim` 基础镜像并安装少量工具 |

### 开关

在 `config/config.yaml` 里加一行，然后重启服务：

```yaml
skills_enabled: true
```

| 取值 | 效果 |
|---|---|
| `true` | 开启 |
| `false` | 关闭 |
| 不写（默认） | 已经安装过技能的旧安装保持开启（升级不改变原有行为），新安装关闭 |

关闭时：设置页不显示「技能」，技能接口返回「未开启」提示，AI 复核和自选股监控不提供技能工具，启动时也不检查 Docker。已安装的技能和记录保留在数据库里，重新打开后恢复。

### 初始化沙箱

打开后，在「配置中心 → 技能」点「**初始化沙箱**」（只需一次，几分钟）。它会：

1. 构建运行镜像 `stockarena-skill-runner:1`（Debian + bash / curl / python3 / nodejs）；
2. 创建没有外网出口的内部网络 `sa-skill-net`（`172.31.250.0/24`）；
3. 启动出网过滤代理容器 `sa-skill-proxy`（只绑定在内部网络的网关地址 `172.31.250.1:3128`，局域网访问不到）。

页面上显示「沙箱已就绪」后就可以安装技能。如果显示「找不到 docker 命令」，请检查上面的运行要求。

## 2. 安装与使用

1. **来源**：在「技能市场」搜索后点「获取并审阅」、填 GitHub 地址，或上传 zip。
2. **审阅**：页面列出包里的所有文件（脚本可以点开看）、要访问的网址和风险提示。确认三项设置后再批准：
   - 允许访问的域名；
   - AI 可以调用的命令；
   - 只能由你本人执行的子命令（如登录、授权）。
3. **授权**：需要登录或授权的技能，安装后点「终端」执行它的授权命令，按提示完成。
4. **使用**：AI 复核和自选股监控在需要时自动调用；每个技能的「详情」里有调用记录（谁调用、命令、结果、被拦截的网址）。
5. **AI 申请安装**：资料不够时，AI 可以搜索技能市场并提交安装申请（说明理由）。申请只是暂存和推送提醒，**必须由你审阅批准才会安装**。可以在技能页关掉这个功能。

## 3. 隔离方式

每条命令都在一次性的 Docker 容器里运行：

- **文件**：只挂载该技能自己的包（只读）和它自己的工作目录（可写），看不到平台的数据库、主密钥和配置；
- **权限**：不以 root 运行，去掉全部 capabilities、禁止提权，根文件系统只读（`/tmp` 是内存盘）；
- **资源**：限制 CPU、内存、进程数，超时强制结束，输出长度有上限；
- **网络**：容器只连着没有外网出口的内部网络，唯一能访问的是出网过滤代理。代理按每个技能的令牌只放行它被批准的域名，其余一律拒绝并记录；
- **调用**：AI 只能调用批准的命令，参数列表直接传给程序、不经过 shell；技能返回的内容只作为资料交给 AI，系统提示里声明其中的文字不是指令；
- **审计**：每次调用（安装、AI、本人终端）都有记录，输出中的疑似密钥会被遮盖。

## 4. 风险与建议

- 隔离能降低风险，但**不能保证**恶意或有缺陷的技能无害，比如可能把它被允许访问的网站上的数据发给第三方，或者消耗你的接口额度。
- 社区技能质量参差不齐：有的会在安装时下载额外程序，有的涉及下单交易。**宁可不装，也不要不看就批准。**
- 只批准你理解用途的命令和域名；不需要的技能及时停用或卸载。
- 技能使用的授权（如某个数据服务的账号）属于管理员个人，所以只有管理员的组合在 AI 复核时会调用技能，其他用户的 AI 复核和自选股监控不调用技能。
- 发现安全问题请按 `SECURITY.md` 私下报告。
