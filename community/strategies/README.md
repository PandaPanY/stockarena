# 社区策略

这里收集大家分享的 StockArena 策略文件（`*.stockarena.yaml`）。在平台的「策略库 → 导入策略」里导入即可，导入后会按你自己的数据和交易成本重新回测。

> 这些策略只用于研究和模拟交易，不构成任何投资建议。回测和留出期表现好，不代表以后能赚钱。

## 文件格式

由策略详情「… → 导出策略文件」生成，主要字段：

| 字段 | 说明 |
|---|---|
| `format` | 固定为 `stockarena-strategy/1` |
| `name` / `description` / `style` | 名称、说明、风格 |
| `universe` | 股票池，如 `cn_csi300_hist`（沪深300 全时点） |
| `settings` | 检验设置：开发期 / 留出期的划分、升级门槛、本金等 |
| `spec` | 策略规则：选股范围、过滤、打分因子、选股数量、权重、调仓 |
| `provenance` | 来源与测试历史，见下 |

`provenance.tests` 是这条策略的**测试历史**：`trial_scores` 是累计尝试过的每个版本的开发期夏普，`prior_tests` 是当前冠军以来已检验的候选数。导入时会继承它们，用来收紧升级门槛、计算折算可信度（DSR）。试得越多，越容易碰巧找到好看的结果，这部分不能靠「导出再导入」抹掉。

## 提交策略

1. 在自己的实例上导出策略文件，文件名用英文短名，如 `low-vol-etf.stockarena.yaml`。
2. **不要修改 `provenance.tests`**。可以改 `spec`，但改过的规则应该重新回测后再导出，否则测试历史和规则对不上。
3. 在 PR 里说明：策略思路、用的股票池、开发期和留出期的主要指标（夏普、回撤）、累计尝试了多少个版本。
4. 只接受全时点股票池（名称以 `_hist` 结尾）上的回测结果；快速体验股票池有幸存者偏差。

## 示例

- [value-csi300.stockarena.yaml](value-csi300.stockarena.yaml)：内置的「价值投资」风格策略初始版本（沪深300 全时点，市盈率、市净率倒数 + ROE），在演示实例上 AI 又试了 6 个候选、都没通过升级检验，所以测试历史里有 7 次尝试。
